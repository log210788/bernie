# 📋 Emergency Field English Cheat Sheet
## Guía Rápida de Campo: Inglés para Socorristas

Guarda este archivo en tu teléfono o imprímelo para consultas rápidas en el terreno o comunicaciones por radio.

---

### 🚨 1. Palabras Cruciales (Must-Know Words)

| Inglés | Español | Pronunciación |
| :--- | :--- | :--- |
| **Survivor** | Sobreviviente | *ser-VÁI-ver* |
| **Injured** | Herido / Lastimado | *IN-djerd* |
| **Trapped** | Atrapado | *TRAPT* |
| **Missing** | Desaparecido | *MÍS-ing* |
| **Displaced** | Desplazado (sin casa) | *dis-PLÉIST* |
| **Shelter** | Albergue / Refugio | *SHÉL-ter* |
| **Safe zone** | Zona segura | *SÉIF-zóun* |
| **Supplies** | Suministros / Provisiones | *sa-PLÁIS* |
| **Shortage** | Escasez / Falta de | *SHÓR-tidch* |
| **Evacuate** | Evacuar | *i-VÁK-yu-eit* |
| **Assess** | Evaluar / Valorar | *a-SÉS* |
| **Distribute** | Distribuir / Repartir | *dis-TRÍB-yut* |
| **Urgent** | Urgente | *ÉR-djent* |

---

### 📦 2. Suministros Comunes (Supplies)

* **Clean water** *(klin WÓ-ter)* = Agua limpia / potable
* **Blankets** *(BLÁN-kets)* = Cobijas / Mantas
* **First aid kit** *(FERST-éid kit)* = Botiquín de primeros auxilios
* **Tents** *(tents)* = Carpas / Tiendas de campaña
* **Canned food** *(kand fud)* = Comida enlatada
* **Baby formula / food** *(BÉI-bi fór-myu-la)* = Leche / comida para bebés
* **Flashlights / Batteries** *(FLÁSH-laits / BÁ-te-ris)* = Linternas / Pilas

---

### 📻 3. Fórmulas de Radio y Llamadas (Radio Phrases)

| Situación | Qué decir en inglés |
| :--- | :--- |
| **Pedir ayuda urgente** | *"This is an emergency. We need immediate assistance at [lugar]."* |
| **Pedir agua/comida** | *"We have a critical shortage of [water / food]."* |
| **Reportar heridos** | *"We have [número] injured people. We need a doctor."* |
| **Reportar carretera bloqueada** | *"The road is blocked. Trucks cannot pass."* |
| **Confirmar recepción por radio** | *"Copy that."* *(Copiado / Entendido)* |
| **Pedir que repitan** | *"Say again, please."* *(Repita, por favor)* |

---

### 🗣️ 4. Instrucciones Directas al Público (Crowd Instructions)

* **"Please move to the safe zone."** *(Por favor, muévanse a la zona segura.)*
* **"Do not enter the building. It is dangerous."** *(No entren al edificio. Es peligroso.)*
* **"Please wait in line for water."** *(Por favor, esperen en fila para el agua.)*
* **"Is anyone injured or trapped?"** *(¿Hay alguien herido o atrapado?)*
* **"Help is on the way."** *(La ayuda está en camino.)*
